# Video Forge0.7.0 — videos authored in code

Write and refine short-form videos directly in React/TSX, HTML/CSS, SVG, Canvas and WebGL with Claude Code or Codex. Custom composition projects now sit alongside the existing version-1 renderer.

- `init` creates an ordinary editable project with pinned dependencies, local fonts, original motion helpers and a frame score. `run`, `preview`, `review` and preflight accept the project from outside the plugin directory.
- Six composable motion families cover optical refraction/displacement, perspective traversal, parallax, kinetic typography, continuous transitions and rapid editorial motion. Timing comes from frames, including GSAP and shader uniforms.
- Moving drafts preserve frame rate/timing; final profiles use native dimensions, CRF16 H.264 and AAC when present. Output includes source, assets, dependency locks, transcripts/SRT, critical frames and technical reports.
- Rewritten direction teaches cinematic motion in code, continuity, real evidence and readable meaning across fast cuts. Mesh worlds remain optional; all scene types receive pacing inspection.
- A24-second Video Forge film and six15-second-reel studies ship as public demonstrations with editable source. A separate22.5-second private footage benchmark is delivered locally and excluded from GitHub.
- Original100-entry source coverage is retained, with additional pinned motion research and clear attribution boundaries.

Install the `codex` or `claude` archive for runtime hosts, `standalone` for compatible Agent Skills hosts, `claude-skill` for custom skill upload, or `chatgpt` for an instruction/code companion with an explicit rendering handoff. The source archive includes public demonstration media. SHA256SUMS and a release manifest cover published assets.

Validation includes45 unit/contract tests, native render/decode smoke tests, zero-strength optical regression, repeated out-of-order frame capture, all100 source records and six archive/resource checks. One independent Codex application subagent authored and rendered a fresh six-second film using an extracted package. A separate Codex CLI generation attempt hit an account limit and is incomplete. Claude CLI manifest checks pass; actual Claude generation is unverified until signed in. No live paid generation calls were made.

Creative examples are evidence of these particular productions, not a guarantee of aesthetic quality or social performance. Optical glass is an analytic shader rather than a physical fluid simulation. Private footage retains its original detail;60fps motion graphics do not recover missing camera detail.
