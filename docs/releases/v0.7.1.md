# Video Forge0.7.1 — lean source and plugin packages

This maintenance release keeps the creative/runtime capabilities of0.7.0 while removing generated production baggage from the source checkout and install archives.

- Generated videos, duplicate audio/source snapshots and superseded host reports remain available in immutable v0.7.0/prior releases. Git history is preserved.
- One canonical motion helper and standalone scaffold lock generate the example copies during build.
- Explicit distribution inventories exclude productions, caches, secrets and unlisted binary media. Packaging requires an empty output directory; release preparation rejects stale assets.
- Lightweight CLI commands load modules on demand. Media hashing streams files with bounded memory in both rendering paths.
- Shorter directing/editing guidance preserves progressive disclosure and distinguishes version-2 choreography from version-1 editing options.

All six host archives, maintained examples, source records and runtime checks are validated. No new model-quality claim, live Claude generation trial or paid API verification is implied. Public demonstrations: https://github.com/Sanidhya14321/video-forge/releases/tag/v0.7.0

Local before/after measurements: Codex ZIP17.94→1.53MB (about91% smaller); source ZIP83.88→1.54MB (about98% smaller); director875→648cl100k_base tokens. Lightweight help/ideas startup dropped from roughly0.47s/110MB peak RSS to0.11s/48MB in three local samples. Timing/RSS are machine-specific, not cross-host guarantees.
