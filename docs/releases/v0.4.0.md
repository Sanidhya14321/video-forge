Video Forge v0.4.0 makes installation and production handoff clearer across Claude, Claude Code, ChatGPT and Codex, while keeping one shared set of creative instructions.

## Choose the right download

- **Codex:** `video-forge-codex-0.4.0.zip`, or register the Git marketplace and install `video-forge@video-forge-local`.
- **Claude Code:** `video-forge-claude-0.4.0.zip`, or install `video-forge@video-forge` from the Claude marketplace.
- **Claude custom skill:** `video-forge-claude-skill-0.4.0.zip`, with root `SKILL.md` and self-contained resources.
- **ChatGPT chat:** `video-forge-chatgpt-0.4.0.zip`, a small instruction/reference companion for planning and local rendering handoff. It is not a hosted renderer.
- **Other agents:** standalone skill ZIP. Full source and saved demos remain in the source ZIP.

## Improvements

- Full-frame footage layout and eased, editable punch-in windows for portrait edits.
- Nine shared skills, including setup/onboarding and a capability-aware host reference.
- Smaller install archives omit generated demo outputs; prepared example inputs and the full 100-entry source register remain bundled.
- Refreshed README, installation/update instructions, compatibility matrix, changelog, contribution and privacy/security guidance.
- Releases are gated on Linux/macOS validation, all six archive/resource checks, native smoke renders and verified checksums. A draft is uploaded completely before publication.
- Includes both contrasting 30-second reels, side-by-side MP4 and a portable comparison archive. Existing releases remain available.

Claude Code and Codex package discovery/runtime are checked locally. Claude account upload, ChatGPT account invocation, live paid providers and social audience results are not claimed as tested. See the compatibility document and validation record for scope.
