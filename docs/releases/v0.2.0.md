Video Forge now has a native fast-reel workflow, rather than relying on the same heading-and-card structure for every video.

- Twelve original abstract/kinetic motion treatments with deterministic beat timing and seeded variation.
- Directing guidance for visual language, semantic transformations, rhythm contrast, proof holds, match cuts and minimal palettes.
- `review` for timing/repetition/density feedback and `preview` for entry/peak/exit frames without voice or paid execution.
- Flat surfaces, protected text/caption placement, and complete editable renderer snapshots.
- A 30-second, 20-shot monochrome demo with an original 160 BPM score, local AI narration and measured subtitles.
- Twenty-four automated tests, actual TSX type-checking, real FFmpeg checks, host/archive validation, and a model-free treatment render in CI.

Download the Claude, Codex, standalone or complete source ZIP, then follow `docs/installation.md`. Releases include SHA-256 checksums. The demo MP4 shows the new workflow; the agent still authors the story and explicit job, while the CLI executes it.

This release does not claim measured Instagram engagement, a blinded skill-vs-no-skill benchmark, a public plugin-directory submission, or execution support for every engine in the 100-entry source register. Publishing and advanced external editors remain reference integrations.
