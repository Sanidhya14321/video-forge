# Validation scope

Run `npm run check` for TypeScript, renderer types, tests, nine skills, manifest/resource links, lockfiles and all100 source records. CI also renders the legacy product/reel/pop/overlay/world paths and the custom optical fixture on Linux. macOS runs compilation, tests and archive validation; it is not a native-render claim.

The optical regression checks that zero strength preserves the source color. The [out-of-order audit](code-determinism.json) records repeated PNG captures for refraction, DOM blur/traversal, GSAP, transition and editorial mechanisms on one browser/GPU. It does not promise cross-GPU identical pixels. Code-project preflight validates imports/composition/score and captures frame zero before creating output; later-frame resources still need full playback review.

The v0.7.0 benchmarks comprise a24-second public film and15-second motion studies at1080×1920/60fps, plus a private22.5-second edit preserving44/44measured words. Full playback, native critical frames, caption/crop checks, loudness analysis and decoding were completed. [Published productions](../demos/README.md) preserve the original evidence. There was no independent human listening session.

A fresh independent Codex application subagent completed a six-second film through an extracted package. [Trial scope](agent-forward-test.md). A separate Codex CLI attempt hit an account limit; actual Claude generation remains unverified until signed in. Manifest discovery is not a model-quality evaluation. Live OpenAI/fal generation has not been verified; transport tests are mocked.

[Instruction measurements](code-context-measurements.json) count static files, not live model usage or equal-capability upstream comparisons. Neither timing heuristics, effect counts nor technical checks predict aesthetic quality, reach or retention.

Repository cleanup preserves production history in immutable tags/releases. New releases validate the compact packages directly; old media is not recopied into every version. See [release maintenance](releasing.md).
