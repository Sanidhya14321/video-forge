# Six editable motion studies

[Moving preview](https://github.com/Sanidhya14321/video-forge/releases/download/v0.7.0/video-forge-motion-studies-0.7.0.mp4)

`src/Film.tsx` demonstrates analytic refraction, spatial traversal, layered parallax, scoped GSAP type, a continuous portal and rapid editorial motion. Each mechanism lasts150frames at60fps. Optical effects require the pinned rendering browser. These are mechanisms to compose, not a finished-story template.

Run `npm run build` in the toolkit to materialize `lib/index.tsx` from canonical `motion/index.tsx` and the standalone package/lock from `templates/short/`. Then:

```sh
node /absolute/toolkit/dist/cli.js preview /absolute/toolkit/examples/motion-studies/project.json --out /absolute/new-draft
```

Runtime/source archives already include these derived resources. To work independently, copy the example outside the installation, run `npm ci` there, and use Remotion normally. CLI delivery preserves local helpers and dependencies with the composition.
