# Editable short

Edit `src/Film.tsx`, `score.json`, and `public/`. All time comes from frames. Run through the Video Forge CLI: `preview project.json --out ../draft`, then `run project.json --out ../final`.

For standalone Remotion authoring, run `npm ci`, then `npx remotion studio src/index.tsx` or `npx remotion render src/index.tsx Film output.mp4`. Use the pinned browser for optical effects; see the plugin motion references. Assets stay inside `public/`; import source only within this project. Keep provenance and licenses with supplied media.
