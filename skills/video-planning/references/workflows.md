# Planning and reference analysis

## Brief to storyboard
Record audience, one-sentence message, evidence, duration, aspect ratios, available assets, and pronunciation notes. A useful scene table includes start/end, visual action, exact on-screen text, narration, and the evidence or asset that supports it. Keep spoken and displayed copy complementary so the frame is not a transcript wall.

Choose one technical payoff: a faster operation demonstrated with measured data, a bug explained with a reproducible example, or a concept made visible. If a number is illustrative, label it. Use a tiny input that the viewer can follow in one pass.

## Reference video breakdown
Probe duration and frame rate. Extract frames at shot changes and sample within long shots. Transcribe audio when available. Record what is observed: framing, camera movement, type scale, beat changes, caption style, asset transitions, and sound cues. Mark inferred editorial intent separately. A still image cannot establish motion or timing.

Distill reusable patterns such as setup/payoff, a carried object across shots, revealing an interface after the spoken cue, or emphasis landing with a sound hit. Do not carry a reference creator's identity, music, claims, or product assets into a new brief without appropriate rights.

## Scripting
Read a technical script aloud. Expand ambiguous abbreviations in narration, simplify nested clauses, and preserve exact code on screen. Keep a source-to-claim list when the topic depends on research. Check each scene for a visible change in the viewer's understanding.

YouTube transcript and research tools in the register have separate authentication and retrieval behavior. Video Forge does not ship a YouTube downloader. Use supplied transcripts or an explicitly configured external tool, retaining video identity, retrieval date, language, and timing origin.
