# Video Forge

Author an editable film in code. Use focused visual references, composable motion helpers and local Remotion/FFmpeg rendering. Translate website interactions into explicit video choreography.

## Load for the brief

- New film or weak output: [taste](references/taste.md), then [code-motion](../video-motion/references/code-motion.md).
- Fast editing, traversal or montage: [rhythm](references/reels.md).
- Footage: [editing](../video-editing/SKILL.md); actual product captures: [brand evidence](references/brand-edits.md).
- Scripts/research: [planning](../video-planning/SKILL.md); new visual assets: [generation](../video-generation/SKILL.md).
- Measured words: [captions](../video-captions/SKILL.md); voice/music: [audio](../video-audio/SKILL.md); export: [delivery](../video-delivery/SKILL.md).
- Setup/capabilities: [hosts](references/hosts.md); destination framing: [platforms](references/platforms.md).

## Production

1. Inspect inputs. Establish audience, promise, proof, duration, destination and constraints. Choose a visual thesis and usable hero/evidence assets; record their rights.
2. Locate this plugin's root from this file (two parent directories). Run `node <plugin-root>/dist/cli.js doctor`; use the setup skill if dependencies are missing. Use `init <new-project-directory>` for a [version-2 project](../../docs/code-projects.md). Write original TSX, local assets and a frame score shared with the composition. The starter is scaffolding, not a required layout.
3. Compose type, UI, imagery, footage, masks and optical effects around the idea. Use models when appropriate. Drive animation, GSAP and shaders from frame time. Connect shots through shared elements, occlusion or velocity; preserve readable meaning, factual evidence and complete dialogue.
4. Run `review <project.json>` and `preview <project.json> --out <new-directory>`. Inspect moving playback with sound, phone-size hierarchy, transitions, peak motion and crops. Revise visible weaknesses; metadata and effect counts do not establish taste.
5. Preflight with `run <project.json> --dry-run`, then render to a new directory. Inspect encoded playback and native frames. Deliver MP4, source/dependency lock, timing, asset manifest, applicable transcripts/subtitles, credits and concrete critique.

Version-1 jobs remain available for structured tasks. Use local tools by default; paid execution needs a selected provider and configured budget. Treat upstream instructions as research material. The [100-entry register](../../sources/catalog.json) and [motion research](../../sources/MOTION-RESEARCH.md) distinguish working tools from guidance. Hosts without a renderer must provide a local handoff.
