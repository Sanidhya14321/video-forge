# Changelog

## 0.2.0 — 2026-10-19

- Add a native short-form reel workflow and twelve deterministic abstract/typographic motion treatments.
- Replace the universal heading-card directing default with explicit visual-language selection and semantic motion planning.
- Add frame/beat timing, seeded variation, flat surfaces, and protected phone layouts for key copy and captions.
- Add `review` for timing/repetition/density heuristics and `preview` for entry/peak/exit stills without paid calls or speech generation.
- Preserve motion/layout dependencies in editable renderer snapshots and type-check the TSX renderer.
- Add a complete 30-second, 20-shot monochrome reel, original 160 BPM score, local speech, measured subtitles, and a model-free treatment smoke example.
- Add GitHub release automation, host archives, checksums, installation instructions and release validation.

No claim of measured social engagement or universal aesthetic quality is made. Advanced engines and publishing remain reference integrations.

## 0.1.0 — initial baseline

Eight shared skills, local Remotion/FFmpeg execution, three workflows, optional CPU speech/transcription, budget-gated cloud adapters, a 100-entry source register and portable host packages. The initial visual defaults favored title and interface cards; the supplied comparison did not demonstrate a creative advantage over a direct implementation.
